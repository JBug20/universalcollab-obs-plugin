# UniversalCollab for OBS

An OBS Studio plugin that brings UniversalCollab into regular OBS, for people who don't want to install a separate app. All other OBS plugins keep working alongside it.

This repo is one of three:

| Repo | What it is |
|---|---|
| `universalcollab-app` | The desktop app (Electron) that controls OBS from outside |
| **`universalcollab-obs-plugin`** | This repo: the OBS plugin |
| `universalcollab-relay` | The optional relay server both connect to |
